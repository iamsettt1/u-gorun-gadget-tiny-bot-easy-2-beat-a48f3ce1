A deterministic, long-only trend + pullback trading bot for Solana hourly bars (FARTCOIN, JITOSOL, POPCAT, RAY, SOL, WETH, WIF). It rides uptrends with EMA 12/26 pullback entries, exits on trend flips, volatility-scaled trailing stops, hard stops and take-profits, and sits in cash through downtrends — beating buy-and-hold by losing less when the market falls and capturing the trend when it rises.

## Run it

```sh
node main.ts
```
